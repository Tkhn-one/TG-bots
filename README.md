# FocusFlow — Telegram-планировщик задач

FocusFlow — портфолио-проект Telegram-бота для личных задач и напоминаний. Он помогает быстро добавить задачу, выбрать дедлайн, получить уведомление и отметить результат, не выходя из Telegram.

## Возможности

- пошаговое создание задачи: текст, срок, приоритет, повторение;
- быстрые сроки: через 15 минут, через час, сегодня вечером, завтра утром; либо точная дата и время;
- разовые, ежедневные и еженедельные задачи;
- напоминания с кнопками **«Готово»**, **«+10 минут»** и **«+1 час»**;
- список активных задач и просмотр каждой задачи;
- настройка часового пояса IANA (`Europe/Moscow`, `Europe/London` и др.);
- автоматическая очистка завершённых задач по истечении 30 дней;
- SQLite — отдельный сервер базы данных не нужен;
- Docker-образ и Docker Compose.

## Как пользоваться

1. Откройте бота и отправьте `/start`.
2. Нажмите **«Новая задача»**.
3. Напишите задачу, например: `Позвонить в сервис`.
4. Выберите срок, приоритет и повторение.
5. В назначенное время бот отправит уведомление. Нажмите **«Готово»** или отложите его.
6. В разделе **«Мои задачи»** доступны все активные задачи.

Команды: `/start` — главное меню, `/tasks` — активные задачи, `/help` — подсказка.

## Локальный запуск

### Требования

- Python 3.11+ (рекомендуются Python 3.12 или 3.13);
- токен Telegram-бота от [@BotFather](https://t.me/BotFather).

```powershell
git clone --branch arena/019fe890-tg-bots --single-branch https://github.com/Tkhn-one/TG-bots.git
cd TG-bots
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и вставьте токен:

```dotenv
BOT_TOKEN=123456789:реальный_токен_от_BotFather
DATABASE_PATH=data/task_planner.sqlite3
COMPLETED_TASK_RETENTION_DAYS=30
```

Запуск:

```powershell
python -m app.main
```

На Linux/macOS вместо активации Windows используйте `source .venv/bin/activate`, а вместо `Copy-Item` — `cp .env.example .env`.

## Старые данные Avito

Код мониторинга Avito полностью удалён. Старый файл `data/avito_watcher.sqlite3`, если он есть, не читается новым проектом и останется резервной копией. Новый бот создаст отдельную базу `data/task_planner.sqlite3`.

Когда убедитесь, что старый файл больше не нужен, его можно удалить вручную:

```powershell
Remove-Item .\data\avito_watcher.sqlite3
```

Не удаляйте `.env`: в нём хранится токен бота.

## Docker

```powershell
Copy-Item .env.example .env
# укажите BOT_TOKEN в .env
docker compose up --build -d
docker compose logs -f bot
```

Остановить: `docker compose down`.

## Хранение и производительность

В базе остаются активные задачи и недавняя история завершённых. Завершённые задачи очищаются автоматически по `COMPLETED_TASK_RETENTION_DAYS` (стандартно 30 дней). Планировщик опрашивает БД раз в 20 секунд, а не создаёт отдельный поток или запрос к внешнему сервису для каждой задачи. SQLite с такой нагрузкой хорошо подходит для личного бота и небольших команд.

## Ограничения

- Бот должен быть запущен в момент дедлайна. Для постоянной работы используйте сервер или Docker на постоянно включённой машине.
- Telegram-бот не может первым написать пользователю: сначала нужно открыть бота и нажать `/start`.
- Повторяющаяся задача создаёт следующее повторение после нажатия «Готово».
- Не добавляйте `.env` или файл базы данных в Git.
