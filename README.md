# Avito Watcher — Telegram-бот уведомлений

Портфолио-проект: Telegram-бот следит за несколькими сохранёнными поисками Avito и отправляет в личный чат ссылки на объявления, которые появились после первоначального сканирования.

> **Важно.** Это не официальный клиент Avito. Публичная HTML-разметка сайта может изменяться, а Avito может временно ограничивать автоматические обращения или показать CAPTCHA. Проект **не обходит** CAPTCHA, авторизацию, технические ограничения или правила сайта. Перед эксплуатацией проверьте актуальные условия Avito и, если для вашей задачи доступна официальная интеграция/API, используйте её вместо HTML-парсинга. Не ставьте частые интервалы: минимум в проекте — 5 минут.

## Возможности

- создание поиска из ссылки на уже отфильтрованную страницу Avito;
- любые критерии, которые поддерживает ссылка Avito: запрос, город, категория, цена, продавец и т. д.;
- несколько независимых поисков для одного пользователя;
- первый обход без спама: бот запоминает существующие карточки и уведомляет только о последующих;
- кнопки для просмотра, приостановки, возобновления и удаления поиска;
- SQLite без отдельного сервера БД;
- мягкая обработка сетевых ошибок, HTTP 403/429 и CAPTCHA.

## Как пользоваться ботом

1. Откройте [Avito](https://www.avito.ru/) в обычном браузере.
2. Выполните поиск и установите все нужные параметры: город, категорию, цену, состояние и другие фильтры.
3. Скопируйте **полный адрес страницы результатов** из адресной строки. Он должен начинаться с `https://www.avito.ru/` или `https://avito.ru/`.
4. В чате с ботом нажмите **«Новый поиск»**.
5. Укажите понятное название, вставьте ссылку и выберите интервал в минутах.
6. Дождитесь первой проверки. Бот сохранит уже показанные объявления как исходную точку, поэтому не будет присылать старую выдачу.
7. Когда в выдаче появится ранее не встречавшееся объявление, бот пришлёт карточку с названием, ценой/локацией (если доступны) и кнопкой-ссылкой.
8. В **«Моих поисках»** можно поставить мониторинг на паузу, снова включить или удалить.

Команды: `/start` открывает меню, `/help` показывает краткую подсказку.

## Быстрый запуск локально

### Требования

- Python 3.11+ (проект проверялся с Python 3.12);
- Telegram-аккаунт;
- токен бота от [@BotFather](https://t.me/BotFather).

### 1. Создайте Telegram-бота

1. Откройте `@BotFather` в Telegram.
2. Отправьте `/newbot`, задайте имя и username.
3. Скопируйте выданный токен. Токен даёт полный доступ к боту — никому его не отправляйте и не добавляйте в git.

### 2. Установите проект

```bash
git clone https://github.com/Tkhn-one/TG-bots.git
cd TG-bots
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
```

На Windows, если команды `cp` нет:

```powershell
Copy-Item .env.example .env
```

### 3. Настройте `.env`

Откройте созданный файл `.env` и замените значение `BOT_TOKEN`:

```dotenv
BOT_TOKEN=123456789:реальный_токен_от_BotFather
DATABASE_PATH=data/avito_watcher.sqlite3
MIN_CHECK_INTERVAL_MINUTES=5
LOG_LEVEL=INFO
```

`DATABASE_PATH` — путь к локальной SQLite-базе. В ней хранятся только настройки поисков и идентификаторы уже увиденных объявлений. Файл `data/*.sqlite3` не попадает в git.

### 4. Запустите

```bash
python -m app.main
```

Откройте созданного бота в Telegram и отправьте `/start`. Остановить процесс можно сочетанием `Ctrl+C`.

Проект использует long polling — публичный IP, домен и webhook для локального запуска не нужны. Одновременно должен быть запущен только **один** экземпляр бота с одним токеном.

## Запуск в Docker

Нужны Docker Engine и Docker Compose v2.

```bash
cp .env.example .env
# отредактируйте .env и укажите BOT_TOKEN
docker compose up --build -d
```

Посмотреть логи:

```bash
docker compose logs -f bot
```

Остановить:

```bash
docker compose down
```

Папка `./data` смонтирована в контейнер, поэтому настройки и список увиденных объявлений сохраняются между перезапусками. Для обновления кода:

```bash
docker compose up --build -d
```

## Запуск на сервере

1. Создайте небольшой Linux-сервер с Docker или Python 3.11+.
2. Скопируйте проект на сервер и настройте `.env` так же, как в разделе выше.
3. Запустите через `docker compose up --build -d`.
4. Убедитесь, что `docker compose logs -f bot` показывает `Monitor started` и нет ошибки токена.
5. Настройте резервное копирование папки `data/`: в ней история, предотвращающая повторные уведомления.

Для работы polling входящие порты открывать не требуется. Серверу нужен исходящий HTTPS-доступ к `api.telegram.org` и Avito.

## Архитектура

- `app/bot.py` — Telegram-интерфейс и диалог создания поиска (aiogram 3);
- `app/avito.py` — изолированный клиент/парсер публичной страницы поиска;
- `app/monitor.py` — фоновый планировщик и отправка уведомлений;
- `app/database.py` — SQLite и дедупликация карточек;
- `app/config.py` — переменные окружения;
- `Dockerfile`, `docker-compose.yml` — контейнерный запуск.

## Ограничения и эксплуатационные замечания

- Состав HTML Avito не является стабильным контрактом. Если выдача перестала читаться после изменений сайта, адаптируйте селекторы в `app/avito.py` или подключите разрешённый API.
- Уведомление означает, что карточка новая **для бота**. Она могла быть перевыставлена, поднята в выдаче или уже исчезнуть к моменту открытия.
- Отредактированная ссылка не меняет существующий поиск. Создайте новый и удалите/поставьте на паузу старый.
- При ответах 403, 429, CAPTCHA или ошибках сети бот пропускает текущий цикл, чтобы не создавать лишнюю нагрузку. Сообщение об ошибке пользователю намеренно не отправляется на каждом цикле, чтобы не спамить чат; событие записывается в логи.
- Для нескольких пользователей и большого числа поисков лучше использовать очередь задач, централизованное хранилище и официальный источник данных. SQLite и один процесс — осознанно простой вариант для MVP/портфолио.

## Проверка качества

После установки зависимостей можно быстро проверить синтаксис:

```bash
python -m compileall app
```

Перед публикацией обязательно проверьте вручную: `/start`, создание поиска, первую базовую проверку, паузу/возобновление и удаление поиска.
